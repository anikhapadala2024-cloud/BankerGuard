# BankerGuard 🏦

### Smart Resource Allocation Simulator Using Banker's Algorithm

BankerGuard is an Operating Systems project that demonstrates safe resource allocation and deadlock avoidance using Banker's Algorithm.

## Features

- Resource Allocation Matrix
- Automatic Need Matrix Calculation
- Safe State Detection
- Safe Sequence Generation
- Interactive Resource Request Simulator
- Resource Request Validation
- Unsafe Request Prevention
- Activity Log for Request Decisions
- C Algorithm Integrated with Python Flask Backend

## Technologies Used

- C
- Python
- Flask
- HTML
- CSS
- JavaScript
- Git and GitHub
